# Airbnb Clone

A production-oriented Airbnb-style accommodation marketplace built to strengthen full-stack engineering skills and explore scalable application architecture.

The project will include accommodation discovery, search and filtering, authentication, listings, bookings, reviews, user profiles, and other marketplace functionality.

The project is being developed incrementally with a strong focus on:

* Clean backend architecture
* RESTful API design
* Authentication and authorization
* Database modeling
* Search and filtering
* Error handling and validation
* Production-oriented deployment
* Testing
* AI-assisted development using coding agents

## Project Status

Currently in the project initialization and architecture phase.

No application features should be implemented until the initial scope and architecture have been reviewed.

## Development Philosophy

The project should be developed incrementally.

Each major feature should follow this general lifecycle:

1. Define the requirement.
2. Update relevant documentation.
3. Design the feature.
4. Implement it.
5. Test it.
6. Review the implementation.
7. Update documentation if architectural decisions changed.

AI coding agents may be used to accelerate development, but architectural decisions and important implementation choices should remain understandable to the developer.

## Documentation

Project-level instructions are maintained in `AGENTS.md`.

Architecture and scope documentation are maintained in the `docs/` directory.

The documentation should be treated as the source of truth for project decisions.
